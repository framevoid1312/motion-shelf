## Prompt

```text
THIS IS STUPIDLY F*CKING GOLD

this Opus 5.5 board turns one brief into 18 videos. 25 seconds each, 750 frames, every frame drawn by code. 3 hooks × 3 formats × 2 CTAs

the agent puts "+240% conversion" into a client's launch video. nobody approved that number. it renders beautifully and ships

the board runs the loop from this article: brief, data, engine, review, render, variants. the fake number dies at step two

the core is four lines:

assert(assets.present && fonts.loaded)
assert(cta.fits(slot))
assert(claims.every(c => c.approved))
https://t.co/uIDKXYuwgt(f / 30)

here's how to set it up:
1. brand data in JSON, animation in code. a new client changes the file, not the engine
2. every frame is a function of t. no timers, no CSS transitions. frame 600 renders without frames 0 to 599
3. springs in closed form, so the renderer can jump straight to any frame
4. matrix, not crops. 9:16 stacks the UI, 16:9 puts it side by side

six agents on the board, and the panel I watch is human approval: gate required, auto ship never
```
