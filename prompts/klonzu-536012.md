## Prompt

```text
Use REA to investigate how [feature] works in [an app I own or am allowed to examine].
1. If REA is not installed, run npx rea-agents@latest setup and show me the setup plan for approval first
2. Trace the feature from the UI to the exact functions. Write INVESTIGATION.md: every claim tagged observed, inferred or unknown, with function, file and address
3. Write SPEC.md: behavior, inputs, outputs, edge cases. No copied code
4. Build it from SPEC.md only, in ./my-version
5. Run the same 50 inputs through the original and my version, report the match rate and every mismatch
6. Before trusting a pass, break one comparison on purpose and confirm the test fails
Show every diff first. Do not apply edits until I say go.
```
