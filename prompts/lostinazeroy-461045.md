## Prompt

```text
• Fable 5.2 is the director. It writes the plan, reviews every shot and never renders anything itself
• manim draws the math scenes (3Blue1Brown's own engine, 96K stars)
• Blender renders the 3D shots, driven through an MCP server (34K stars)
• Remotion cuts it together as React code, with captions synced to the frame (72K stars)

Here's how to set it up:

1 → install all 4: manim, remotion, mcp-for-blender, remotion-dev/skills
2 → the skills repo teaches Claude Code the Remotion API before it writes a single frame
3 → give it one sentence and a finish line: "make a 12s explainer on X. done means every frame renders"
4 → Fable reviews each render and writes a numbered fix list. The next pass changes only what's on it
5 → run it at high effort. Long multi-step jobs are where Fable gets cheaper per task than Opus

Links to all 4 repos in the reply. Full Fable 5.2 setup and effort guide in the article below
```
