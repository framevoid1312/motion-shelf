## Prompt

```text
I want to build a learning guide that takes an investor from limited knowledge to being an amazing resources stock analyst. Work out a list of topics someone should understand to be a great analyst, including basics like geology and chemistry if relevant, and a logical learning order (by topic) to get to being able to evaluate and pick mining stocks that will do well. Get Claude Fable (as a subagent) and GPT-6 Astra to check your plan.

When done, start building a rich HTML site that explains all those topics. You have an unlimited image-generation budget, so make it look amazing, with great design and explanations, photos if they help, JS diagrams etc. Get Fable and Astra to check that too, by asking how the design can be improved. When done, host the site so I can open it in a browser.

Feel free to use subagents, and weave in real stock examples to ground it. The core goal is to get from limited knowledge to expert resources analyst as efficiently as possible.
```
