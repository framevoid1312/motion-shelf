## Prompt

```text
【AIでラップMVを作るプロンプト】
画像（ラッパー3人）と曲を渡して、Claude Code にこれだけ頼めばMVまで完成👇

添付の画像（ラッパー3人）と曲で、日本語ラップのMVを作って。

【生成】Seedance 2.5、720p、16:9。参照画像は全部渡す（元写真＋1人ずつの切り抜き）。参照から借りるのは顔・髪・メイク・衣装だけ。背景は借りない。
【構成】
・3人が交互に歌う。歌詞4行ごとにカットを替え、歌う人が画面中央の手前に来る
・1カット10秒前後。イントロとアウトロは歌わないカット
・カットごとに場所・カメラワーク・動きを変える（止まる、寄る、しゃがむ、座る、回り込む）
・ラッパーらしいハンドジェスチャー。歌う人は常にカメラ目線
【口パク】
・各カットのプロンプトに、そのパートの歌詞をひらがなで入れて、AIに同じ歌詞を歌わせる
・生成した声と元曲のボーカルを一語ずつ照合し、映像の速さを区間ごとに調整して元曲に合わせる（AIの声は使わない）
【仕上げ】全カットを結合して元曲を重ね、歌詞字幕とタイトルを入れる
【進め方】まず2カットだけテストして口の合いを確認 → 残りを生成。生成前には毎回クレジットを確認
```
