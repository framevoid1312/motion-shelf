## Prompt

```text
VibeVoice｜40 秒高质量创意种草视频制作

请参考我上传的分镜图，为微软开源项目 VibeVoice 制作一支 40 秒的高质量创意种草视频。

项目地址： https://t.co/zEzxa7XuEY

一、创作目标

我要的不是普通的科技产品介绍，也不是把 GitHub README 做成 PPT 动画。

而是一支视觉审美出色、镜头富有创意、动画流畅、音乐节奏强烈，同时能让观众直观理解 VibeVoice 核心能力的产品种草视频。

整体质感对标专业 Motion Design 工作室的品牌宣传作品。

你拥有完整的创作自由度。

不限制技术路线、动画形式、素材来源或制作工具。

可以使用 Three.js、Remotion、Blender、Canvas、SVG、WebGL、GSAP、FFmpeg、AI 图像与视频生成，以及其他合适的开源项目或工具。

可以混合使用 2D、3D、动态图形、角色动画、动态排版、音频可视化和真实产品演示。

不要求纯代码，也不要求严格复刻分镜图。

分镜图用于传达创意方向，不是限制最终画面的模板。

请根据实际制作效果主动优化构图、运镜、场景、动画和转场。

最终只看成片质量。

二、视频规格

时长：40 秒
画面比例：16:9
分辨率：1920×1080 或更高
帧率：优先 60fps
语言：中文
风格：高级、现代、富有设计感的科技创意动画
音频：有节奏感的背景音乐、必要的音效及真实语音演示
最终格式：MP4

避免廉价霓虹科技风、PPT 式转场、无意义的粒子效果、过度复杂的界面堆砌。

画面要有鲜明的视觉记忆点，不要只靠漂亮的 UI。

三、40 秒完整剧情

第一幕｜声音失控（0–6s）

一段长达 60 分钟的多人录音开始播放。

不同人物的声音混在一起，形成复杂、交错的声音波形。

随着音乐节奏加快，声音逐渐失控，画面充满混乱感。

突然，所有声音停止。

屏幕出现：

「一小时的多人录音，谁说了什么？」

要求：前 3 秒迅速抓住注意力，让观众对接下来的变化产生好奇。

第二幕｜声音有了身份（6–13s）

VibeVoice 登场。

原本混乱的声音开始分离，四位说话人的身份逐渐清晰。

每个人拥有独特的颜色、声音波形和视觉标识。

可以通过人物、抽象角色、动态头像或其他更有创意的方式表现。

四种声音从混乱逐渐变得有序，最终形成清晰的说话人标识。

字幕：

「先分清，谁在说话。」

重点是让观众直观看到说话人识别的能力，而不只是看见四条不同颜色的线。

第三幕｜时间轴魔术（13–23s）

镜头进入声音的内部世界。

一条长达 60 分钟的时间轴逐渐展开。

不同说话人的语音片段被自动标记，并生成对应的文字与时间戳。

每当一个人说话，其对应的声音轨迹和文字同时出现。

镜头可以穿梭于声音、人物、文本和时间轴之间，呈现连续、有节奏的视觉变化。

字幕：

「谁说的，什么时候说的，说了什么。」

「一次整理清楚。」

这一幕是全片的核心高潮，需要最强的视觉表现力。

第四幕｜混乱变成秩序（23–33s）

镜头拉远，刚才复杂的声音世界逐渐整理成一个清晰、有序的语音记录界面。

四位说话人的内容按照时间顺序排列。

观众可以直观看到说话人、时间戳与识别文本的对应关系。

通过动态镜头与交互演示，让观众理解长音频结构化识别的实际价值。

字幕：

「60 分钟长音频，也能结构化识别。」

注意：60 分钟指官方支持的音频长度，不代表能够瞬间完成识别。

第五幕｜结尾反转（33–40s）

所有声音轨道、人物标识和文字逐渐汇聚。

镜头拉远，前面复杂的声音世界最终变成一个简洁的 VibeVoice 标识。

出现：

VibeVoice

Microsoft · Open Source

https://t.co/NyAnbFjRSR

在观众以为视频结束时，一条小小的声音波形突然再次跳动。

屏幕出现：

「等等，我还有一句！」

伴随一个俏皮的音效，画面结束。

结尾要有趣，不能只是普通的 Logo 动画。

四、视觉与动画要求

你可以重新设计所有场景，但必须保证整支作品拥有统一的美术语言。

重点关注：

视觉创意：尽量用有趣的视觉隐喻表达抽象技术，让声音真正成为画面的主角。
镜头设计：镜头之间具有连贯关系，避免每一幕都是独立的静态画面。
运动质量：动作具有自然的加减速、节奏、重量感和层次。
画面构图：建立清晰的视觉中心，控制留白与信息密度。
动态排版：文字既要清晰易读，也要成为视觉设计的一部分。
音画同步：声音变化、字幕、角色反应和音乐节点准确对应。
情绪变化：从混乱、好奇，到惊喜、清晰，最后用幽默感收尾。

允许为提升成片质量调整镜头时长、动画结构、转场以及视觉表现。

但不要改变核心产品能力，也不要加入未经验证的功能。

五、音乐与声音设计

音乐是这支视频的重要组成部分。

请根据剧情设计一段完整的音乐与音效结构。

开头制造紧张和混乱感；说话人分离时让节奏逐渐清晰；时间轴展开时进入最有冲击力的段落；结尾自然收束并留下一个有趣的声音反转。

可以使用原创电子音乐、Funk、节奏型配乐或其他适合画面的风格。

优先使用真实的 VibeVoice 演示音频。

不强制配音。如果通过音乐、人物声音、字幕和动画能把故事讲清楚，就不要添加多余的解说。

不要为了配音而配音。

六、产品真实性

制作前请阅读 VibeVoice 官方仓库和相关文档，确保产品信息准确。

本片重点展示 VibeVoice-ASR 的：

长音频语音识别
多说话人识别
时间戳生成
结构化文本输出

注意，说话人区分不等同于把混合录音真实分离成多条独立音频文件。

如果无法实际运行 VibeVoice，可以使用官方提供的演示结果进行展示，并明确区分真实输出和概念动画。

不能伪造模型性能、识别准确率或处理速度。

七、制作与质量优化

请自主决定最适合的技术组合和制作流程，不需要拘泥于某一种框架。

可以寻找高质量开源动画库、视觉参考、现成组件或制作工具辅助实现。

但不要为了堆技术而牺牲审美。

制作时遵循以下原则：

先明确全片美术风格、镜头语言和视觉节奏。
按照统一风格完成全部场景。
保证视觉主体、字幕、声音和镜头运动相互配合。
实际渲染并检查关键画面与视频片段。
对人物一致性、动作僵硬、镜头突兀、画面单调、字幕错误和音画不同步等问题主动修正。
如果某种方案实际效果不好，主动更换实现方式，不要坚持错误方向。
优先保证最终作品的整体完成度，而不是单个镜头的炫技效果。

允许反复修改和重新设计，直到形成一支完整、统一、有传播吸引力的作品。
```
