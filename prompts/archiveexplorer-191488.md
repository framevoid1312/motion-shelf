## Prompt

```text
"Read my brand folder and write DESIGN.md. Break down the reference video I give you: pacing, type, transitions. Show me 3 storyboards, then one still per scene for the one I pick. Build every scene in HyperFrames, add music, render a draft. Review it second by second without editing and list the problems. Pass every note to Jev and have it score each one against DESIGN.md: fix now / later / skip. Fix only "fix now". After I approve: cut 3 ad variants with different hooks in 9:16, 1:1 and 16:9, then build the landing page from the same DESIGN.md with the video loop as the hero."
```
