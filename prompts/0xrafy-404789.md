## Prompt

```text
Build "NetWatch": a live dashboard that shows what every app on my computer is doing.
Mac and Windows. Free, open-source, no account, no server, nothing leaves my computer.

Activity Monitor and Task Manager are the quality bar for data, not for looks.
Original name, icon and copy.

## How to work
1. Verify first. Run every data source on this Mac and read its real output before
   relying on it. Write down what works without admin and what doesn't.
2. Measure accuracy before UI. Download a known file, then compare the bytes counted
   with the real file size. Compare the total with `netstat -ib`. Fix any gap first.
3. Build the collectors, then the dashboard, then the deep scan.
4. Verify for real: run it on my Mac, check every state in the browser (loading, empty,
   live, phone width), and test Quit on small test programs, never on my real apps.
5. Have a separate agent review the Windows code against the Windows SDK, because
   there's no Windows machine here. Say clearly what was not tested.
```
