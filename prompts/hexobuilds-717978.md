## Prompt

```text
Set up my game studio around this tree:
1. Write the studio rules to CLAUDE.md: three.js for 3D, seeded random only, touch controls from day one.
2. Ask me up to 5 design questions, then write docs/design.md and docs/style.md. Wait for my OK.
3. Build the ugly core loop first, playable in 30 seconds.
4. Create playtest.mjs with Playwright at phone size. Score the screenshots 1-10 and fix the 3 worst problems until every score is 8+.
5. Commit after every working step.
Show me the plan first. No code until I say go.
```
