## Prompt

```text
I'm uploading a photo of an object I own and I want to see how it's built inside.</context>
<task>Rebuild the object as an interactive 3D model in one HTML file with three.js. Add an Explode button that pulls every part apart, and label each part with what it does.</task>
<rules>Build every part from code so the file runs offline. Use soft studio lighting so it looks like a product render.</rules>
<output>One HTML file I can open, spin, zoom and take apart.

I sell [PRODUCT] online and flat photos don't show buyers what it really looks like.</context>
<task>Build a 3D viewer of my product that buyers can rotate, with colour swatches that repaint it live and clickable hotspots that explain each feature.</task>
<rules>Keep it fast on a phone and match my brand colours [COLOURS].</rules>
<output>One HTML file plus the embed code to paste into my store page.

I want to try furniture layouts before I buy anything or move a single sofa.</context>
<task>Build my room in 3D from these measurements, with furniture I can drag, rotate and swap, and a top-down view next to a walk-through view.</task>
<rules>Keep everything to real scale in centimetres and warn me when a piece blocks a door or walkway.</rules>
<output>One HTML file with a Save Layout button that keeps my three favourite layouts.

I need to explain [TOPIC, e.g. how a car engine or the heart works] to people who switch off at diagrams.</context>
<task>Build an interactive 3D model of it, with a Play button that runs the process step by step and parts that show a one-line explanation when clicked.</task>
<rules>Write every explanation in plain words a 12-year-old understands and keep each step under 10 seconds.</rules>
<output>One HTML file I can share with a class, a team or a client.

My numbers sit in a spreadsheet nobody reads.</context>
<task>Turn this data into a 3D city where each building is one item and its height is the value, with a camera that flies over the city and stops on the 3 biggest stories in the data.</task>
<rules>Use only my numbers, label every building and add a legend so nobody has to guess.</rules>
<output>One HTML file I can present full screen in my next meeting.

I own a 3D printer, or can use one at a library, but I can't use CAD software.</context>
<task>Design [OBJECT, e.g. a phone stand, cable clip or name keyring] from my description, show it as a 3D preview I can resize with sliders, and add a Download STL button.</task>
<rules>Make it printable with no supports, use walls at least 2mm thick and show the final size in millimetres.</rules>
<output>One HTML file that previews the design and exports a print-ready STL file.

I want a scroll-stopping visual for my brand, town or office to post on social.</context>
<task>Build a tiny 3D diorama of it that slowly rotates, with small moving details like cars, people or clouds, and a Record button that saves a 10-second clip.</task>
<rules>Use one colour palette and keep it bright and clean so it reads on a phone screen.</rules>
<output>One HTML file that plays the diorama and records a clip I can upload.
```
