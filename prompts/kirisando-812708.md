## Prompt

```text
You're connected to my Roblox Studio. Build a tower defense game. Before you start, research how popular Roblox tower defense games work, then ask me questions about waves, tower types, co-op and round flow. After I answer, build it: all balance numbers (costs, damage, waves, rewards) in one Config ModuleScript in ReplicatedStorage, game logic in ServerScriptService, controls in StarterPlayerScripts, HUD in StarterGui. The server decides money, damage and placement, never the client. After each system, start a playtest, read the console and fix errors before moving on.

Build the map for this game in Workspace. Theme: toys on a giant kid's bedroom floor. Make one winding enemy path from a spawn portal to the base, mark it with numbered waypoints, and block tower placement on the path. Decorate the sides with big toys (crayons, blocks, a teddy bear, a toy chest) as generated meshes or simple part models. Bright colors, soft lighting, a camera that shows the whole path. Keep the part count low so it runs on phones. Then start a playtest and check that enemies follow the path from start to finish.

Now make it a full game. Add a lobby where players choose a story stage, a story mode with 3 worlds x 5 stages that get harder, and a boss at the end of each world. Add a unit shop where coins buy better toy units, a loadout of 5 slots, a daily reward and a codes menu. Save coins and owned units with DataStore. Make the UI clean and mobile friendly, add settings, sound effects and simple animations. Ask me about anything that changes the structure before you build it.

Scan the whole place for hidden scripts, require( calls and anything that loads outside assets. List what you find before deleting it.
```
