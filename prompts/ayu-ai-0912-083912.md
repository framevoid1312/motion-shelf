## Prompt

```text
架空の大型ロケット（2段式の液体ロケット＋固体ブースター2本、白い機体、名前なし）と
その射点について、CAD図面と Blender 動画を作ってください。

【図面】2D の DXF のみ（3Dモデルの書き出しは不要）。単位 mm、A2 の図枠と表題欄つき。
線は青緑系の「電子の図面」風にし、プレビュー画像は濃紺の背景にする。
1. 射点配置図 S=1:500（ロケットを原点に置き、実際の位置で描く。
移動発射台・排煙溝・アンビリカルタワー・避雷塔・照明塔・水タンク・建屋・海岸線）
2. 射点立面図（南から）S=1:400
3. ロケット外形図・断面図 S=1:250
特記事項に「架空の機体・射場のイメージで、実在の図面ではない」と書く。
寸法は Python の形状モジュール1つで決め、図面と動画の両方がそれを読み込む。

【動画】Blender（EEVEE）、1920×1080・24fps・本編20秒＋ロゴ3.5秒、音つき MP4。
1. 暗闇の床に、シアンに光る射点配置図が中心から走査されて描かれる（真上から）
2. 図面の線が光のワイヤーとして立ち上がる
3. 光の粒（Geometry Nodes）が渦を巻いて昇り、発射台・タワー・ロケットが下から積み上がる
（積み上がった高さより下だけが実体になる。カメラは寄る）
4. 図面がマス目ごとにデジタルに溶け、夜の射点が現れる（海・丘・星空。カメラは引く）。
照明塔が点いて白い機体が浮かび、塔の頂部の赤い灯が明滅する
5. アクセスアームが離れる → カウントダウン → 点火 → リフトオフ。
炎は発光する円錐、噴煙は排煙溝と発射台から湧き、上昇する機体の後ろに煙の柱が残る
6. 上昇するロケットを海の上から見上げたところでタイトル → 最後に指定のロゴ
音は外部素材を使わず Python で合成する
（電子音の BGM、波、カウントダウンの電子音、点火から上昇までの轟音、タイトルの和音）。

【進め方】
- 図面のプレビュー画像を目で見て、文字の重なりを直す
- 本番の前にテスト静止画を数枚描いて確認する（照明の明るさ、炎や光の白飛び）
- 本番レンダーは軽い設定で、PC を休ませながら回す。始める前に所要時間を伝えて了承を取る
```
