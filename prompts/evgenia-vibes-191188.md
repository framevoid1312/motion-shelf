## Prompt

```text
Act as an expert home automation engineer and local API reverse-engineer. I want to connect my smart TV to my local network and control it via an AI agent. 

1. Analyze the attached screenshot of my TV's "Settings -> About" screen to identify the manufacturer, model series, and local protocol standard.
2. Write a lightweight Python/Node script utilizing the local network remote control API (supporting standard local ports/protocols used by official remote apps for this TV brand).
3. The script must expose exactly 3 clean functions: open_app(app_name), navigate_menu(direction), and select_item().
4. Format this script cleanly as a drop-in plugin/tool definition so it can be integrated directly into an autonomous AI agent (like GrokBot) as an external tool. Keep it secure, local-only, and optimized for voice command triggers.
```
