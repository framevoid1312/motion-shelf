## Prompt

```text
claude opus 5.5 lives in a 7-floor tower. 25 open-source repos inside. here's what each floor actually does, and the catch nobody mentions

> 07 data room
 echarts: apache project, handles millions of points, renders svg server-side in node. no browser needed
 observable plot: from the d3 team. a full chart in one line of code. fewer tokens, fewer bugs for claude
 rule: verify the number before you animate it. a beautiful wrong chart is just a faster lie

> 06 taste room
 motion design skill (lottiefiles): teaches claude easing, timing, what enters first
 remotion agent skills: official, written by the remotion team
 claude motion design: the reference-to-spec workflow
 this floor is why output stops looking "ai-generated". skills are taste you can install

> 05 motion room
 hyperframes (heygen): html in, video out. ~76k stars, apache-2.0
 remotion: react components  mp4. ~69k stars. catch: free for you, paid license for companies with 4+ people
 motion canvas: typescript generators, built for explainers, live editor preview
 revideo: motion canvas turned into a render api. one template → thousands of personalized videos

> 04 web room
 gsap: 100% free since the webflow deal, including splittext and morphsvg that used to be paid
 motion (ex framer motion): ~35k stars, springs and layout animations
 lottie web: plays after effects exports as json. ~32k stars, airbnb-born

> 03 3d room
 playcanvas: webgl + webgpu engine, renders gaussian splats in a browser tab
 model-viewer: google's web component. one html tag = a rotatable 3d model with ar
 ogl: tiny webgl library. shaders without three.js weight

02 sound room
 kokoro: 82m-parameter tts, apache-licensed. runs on a laptop
 tone.js: renders audio offline. same code = same soundtrack, frame-perfect sync
 audiocraft (meta): musicgen + audiogen, text → music and sfx. catch: weights are non-commercial

01 edit + ship
 hyperframes student kit: cuts pauses and stumbles, adds subtitles
 editly: describe an edit in json, ffmpeg does the rest
 playwright: open the page, seek to frame n, screenshot. repeat 60 times a second. that's the whole renderer
 handbrake: the final encode. right size, right codec, every platform

the trick: pick one repo per floor and give claude the whole brief at once:

claude "make a 30s promo from our q3 numbers.
data: observable plot. taste: motion design skill.
motion: remotion. web: gsap. sound: tone.js.
ship: playwright. 1080x1350, captions on.
```
