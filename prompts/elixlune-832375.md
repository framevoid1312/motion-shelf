## Prompt

```text
Write a single self-contained HTML file with a full-screen canvas animation in pure code. No libraries, no images, no external files.

16,000 particles, mostly silver with about 20% crimson, on a near-black background with faint drifting smoke and stars.

A 44-second loop with a 3D camera that slowly orbits:
1. Particles drift in chaos
2. They flow into a sphere lit from one side
3. The sphere shrinks and a flat ring system forms around it, like a planet
4. Everything morphs into a (3,7) torus knot
5. Then into a 3-arm spiral galaxy
6. It bursts outward and returns to chaos

Make transitions staggered so particles flow rather than jump. Use additive blending, depth fade and soft glow. Click for fullscreen, space to restart.
```
