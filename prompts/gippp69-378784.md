## Prompt

```text
Build me a second brain in Obsidian, based on Karpathy's idea, that runs itself on my $20 Claude plan.

1. Create a vault with folders: inbox, notes, people, projects, daily, archive.
2. Write a contract file in the vault root: one idea per note, every note links to at least 2 others, nothing gets deleted, only archived.
3. Set up 3 skills:
• capture: anything I drop in inbox gets cleaned, tagged and filed
• connect: find related notes and add links both ways
• brief: every morning write a short daily note with what changed and what I should look at
4. Workers:
• Opus 5.5 as the librarian (structure, links, the contract)
• Haiku 5.5 as the scout (cheap first pass on new stuff)
• Sonnet 5.5 as the answerer (when I ask questions about my notes)
• A router that sends each job to the cheapest model that can do it
5. Night shift: once a day, when I'm offline, process the inbox, fix broken links and update the brief.
6. Track spend and stop if the month goes over $25.
7. First run: ask me 5 questions about my work, create the first 20 notes from my answers and show me the graph.
```
