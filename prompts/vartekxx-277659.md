## Prompt

```text
Build me a free tool for Mac (and Windows) that shows live, per app:
1) which apps send and receive data, how fast, and to which servers
2) which apps use the most energy and CPU
3) which apps keep my computer from sleeping
Plus a "Deep scan" button: 20 seconds of measuring, then a report of what
drains my battery or slows my laptop, with the measured number for each reason.

Rules: one Python 3.8+ file, standard library only. It starts a local web
server and opens a clean live dashboard in my browser, light theme.
Launchers: .command for Mac, .bat for Windows.
Read only: never quit apps without my click and a confirmation.
Nothing leaves my computer. Never show a number you didn't measure.
Check every data source on my Mac before you rely on it.
```
