## Prompt

```text
Set up my game studio:
1. Write GAME_DESIGN.md: pitch, core loop, how you win and lose, and a cut list. Wait for my OK.
2. Create subagents for engine (three.js), art and audio, each with its own instructions.
3. Create a playtest subagent that opens every build with Playwright, takes screenshots and scores feel, difficulty and clarity 1-10.
4. Split the build into one-hour jobs in TASKS.md and do them one at a time.
5. After each job, playtest, fix the 3 worst problems, then move on.
6. Add a rule to CLAUDE.md: stop and ask me before any feature that isn't in GAME_DESIGN.md, when a playtest score drops, and before calling a build done.
Show me the plan first. No code until I say go.
```
